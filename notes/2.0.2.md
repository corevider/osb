# Attack rotations for every monster class

- Combat > Skills has one attack rotation per monster class: Normal, Champion, Party, Giant, Party champion, Party giant, Elite and Unique.
- An empty rotation uses the next filled class below it in that order, down to Normal, and its tab says which one, for example "Empty: uses Party giant".
- Your existing rotations stay. Party champions and party giants start with a copy of your Party rotation, so they fight as before.
- The SoX chime and notice now have one switch per seal: Star, Moon and Sun. If the chime was on, all three are ticked; if it was off, none are.
