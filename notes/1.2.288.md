# Alchemy queue: no more picking the elixir by hand
- Fixed: an item in the alchemy queue kept the elixir picked last. With the other grade of elixir in the bag it stopped on "no elixirs" until you picked one by hand.
- New queue items now start on "Any compatible elixir".
- A picked elixir is used first, and when none of it is left, any other elixir of the same kind is used. This also helps queues you already saved.
> Tested in simulation, not in a live game.
