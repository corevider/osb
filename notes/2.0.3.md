# Fewer silent stops, town trips that retry, pet loot to your bag

- A monster the bot cannot reach no longer stops hunting when the game does not confirm that it was released. The bot asks again once, then leaves that monster alone for a minute and hunts on. Protect party members follows the same rule.
- Every stop now says why in the log, for example "Hunting stopped: stopped by you (F8)". A stop you make (F8, Start / stop, Stop all, or a stop from OSB Manager) is never undone; a stop the bot makes by itself is started again after 2 minutes when "Start again when the bot stops by itself" is on.
- Auto-start no longer gives up when the page was reloaded or the connection came back: it waits for the reconnect.
- The same game refusal and the same missing skill icon appear at most once a minute, with a count.
- Town trips no longer stop when the warehouse, a merchant or the world statue does not open, for example while the town is still loading. The bot waits, walks back and tries again, three tries per service.
- New option under Loot, Bag and pet space: "Move pet loot to my bag when the pet is nearly full". The loot is stored or sold on the next town trip like pet loot.
- Reverse Return Scrolls have one switch on the Town page: "Buy Reverse Return Scrolls from the Item mall (silk)". No merchant sells them for gold, so the merchant switch is gone; if it was on, the Item mall switch is turned on. Nothing is bought while the silk budget is 0.
- Item mall "low stock ≤" now includes the number itself, so a low mark of 0 buys when the item runs out.
