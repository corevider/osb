# Error reports and performance data under one privacy switch

- Privacy: Settings → Privacy → **Share usage statistics, error reports and performance data** (off by default) is now one switch for usage statistics, error reports and performance data.
- Error reports: when the switch is on and the OSB server asks for them, OSB sends which part of OSB failed and how (the error type, a fixed message and the place in OSB's code), why the bot stopped by itself, the game phase and what the bot did just before, all as fixed codes. It never sends the text of your log, names, chat or positions.
- Performance data: with the switch on and the server asking for it, OSB sends one entry about every 30 minutes: how long the bot's steps and the pauses between them took, the number and total time of browser freezes, and the page's memory use, with the OSB version. Nothing is timed while sharing is off.
- Settings → Privacy → **Show what is sent** shows the next error report and the next performance entry.
- If you shared usage statistics before, the text of the switch changed, so sharing is now off. Tick it again if you want to keep sharing.
- Inside OSB Manager, the Manager's own switch decides, and the Manager sends OSB's reports together with its own.
- The report window's text changed: your description and details are never copied into a public GitHub issue.
