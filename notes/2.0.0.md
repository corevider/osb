# OSB 2.0.0

- Based on version 1.2.224 of the previous bot. Your settings, share codes and backups carry over.
- Bug reports no longer go to the previous bot's server. Preview the report, then copy it or save it as a file and attach it to a GitHub issue, or press Send and confirm to send it to the OSB team at api.osb.lol. You choose bug report or feature request, you can add a screenshot of a tab you pick, and you get a report code. Nothing is sent before you confirm.
- New: Settings → Privacy. "Share usage statistics" is off by default; when you turn it on, OSB sends a short status report about every 10 minutes to api.osb.lol, linked to a random install ID. "Show my characters in the OSB dashboard" is a second, separate switch. You can see what is sent, download your data, or delete it. Turning the statistics off deletes your data from the server. With both switches off, OSB sends nothing to api.osb.lol. The same section has "Check GitHub for OSB updates" (on by default): the update check carries no data about you, and switching it off stops every update request.
- New from the upstream work up to 1.2.221, all off by default unless said otherwise: wear better gear you carry on town trips, move hunting to the next level spot when a spot gives no XP, a choice of how long to wait for a party resurrection, alert chimes (another player near, death, level up, a unique in view), and a choice of which monsters to avoid when another player is fighting them.
- Item names now show even when the game's data files are not served, and pet loot sells again on town trips. Town trips no longer stop at the smith after a skipped supply. With bag selling on, the weapon merchant now sells the character bag first and the pet loot after it, so a full bag no longer leaves pet loot unsold.
- Reliability fixes from upstream 1.2.222 to 1.2.224: a town trip stops cleanly when the game never settles before the return scroll, an unanswered rebirth is asked again every 10 seconds, combat gear left half swapped by a death or world change is restored quietly while hunting, quest data that fails to load is retried after 10 minutes, the pet-bag-full warning shows with the chime off, Max every skill stops when you leave the world, and settings are saved when you close the page.
- Heads up: the new option to spare giant and party monsters below an HP cutoff is set to 50. It only applies when "Avoided monsters" is "Normal & champion only", which is not the default.
- Town page: picking a town now sets up the town trip by itself (arrival point, warehouse, potion merchant, repair merchant, world statue), and switching the town trip on fills anything still missing. The separate "Set up this town" button is gone and the hand-saving buttons moved under "Adjust by hand (optional)".
- Wear better gear now runs before anything is sold. With bag selling on and a full bag, the weapon merchant no longer sells a piece the warehouse visit would wear.
- Wear better gear no longer compares a necklace, earring or ring with the wrong worn piece. A carried necklace was measured against the weakest worn accessory, even a ring, and the game refused the move ("Inventory rejected: 14"). Every piece now competes only for its own slot, and the plus level counts.
- When the game refuses to wear a piece, or does not confirm it, the bot logs one line, keeps the piece in your bag and does not sell it or try it again this session.
- Loot page: "Pick up drops" is now the first checkbox of the Collection group, in place of the old "Collect drops" further down. It is the same setting as the Turn on button on the Setup page, which still works.
- Gear that asks for a mastery level (for example Lynx Gale Glove or Hydra Gale Breast Mail) is now read correctly: wear better gear considers it when your mastery is high enough, and "Also deposit gear requiring level" now deposits it too, so gear it never matched before may now go to the warehouse.
- Only tested in simulation (a fake server and a virtual clock), not on the live server or against the real api.osb.lol. The game tick was measured with and without a server that never answers.
