# Alchemy buying keeps going until the stones are done
- Fixed: when the bought stones ran out, the queue went back to the merchant only once per item, so the other stones (Str after Int, say) were never bought and the item was skipped.
- Now it goes back every time an item runs out, as long as the last visit bought something.
- The gold limit is now for the whole queue run, not per visit: "Spend at most this much gold per queue run". New default: 100.000.000. A limit you already set stays as it is, so raise it if you want more stones per run.
- When the limit is used up, the log says so, and the item is skipped or the queue stops, as you set.
> Tested in simulation, not in a live game.
