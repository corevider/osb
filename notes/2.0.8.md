# OSB works again after the game's 2026-11-11 update

- Since the game's 2026-11-11 update, the bot stayed on "Waiting for game world" and did not start. The game now sends most of its updates as only the parts that changed, and OSB read each one as the whole game state. OSB now adds each update to the state it already has, so it enters the world and works as before.
